CodeSystem: Retina Conclusion Codes

Official URL: http://dips.no/fhir/RetinaIntegration/CodeSystem/retina-conclusion-code-cs Version: 0.8.1
Draft as of 2025-12-02 Computable Name: RetinaConclusionCodeSystem

Codes for the current or final conclusion of the grading process (1000-series).

This Code system is referenced in the definition of the following value sets:

  • RetinaDiagnosticReportConclusionCodeValueSet

This case-sensitive code system http://dips.no/fhir/RetinaIntegration/CodeSystem/retina-conclusion-code-cs defines the following codes:

CodeDisplayDefinition
1001 KI-gradering (basert på nåværende bilder) This examination is waiting to be graded by the AI system.
1002 Primærgradering (basert på nåværende bilder) This examinations is waiting to be graded by a primary grader.
1003 Sekundærgradering (basert på nåværende bilder) This examination is waiting to be graded by a secondary grader.
1004 Ny fotokontroll (primærgradering) Patient should be scheduled for a new routine eye examination graded by primary grader or AI.
1005 Ny fotokontroll (sekundærgradering) Patient should be scheduled for a new routine eye examination but graded by secondary grader.
1006 Øyelegeundersøkelse (grunnet diabetisk retinopati) Patient is leaving the screening program and should be referred to an ophthalmologist for further examination due to findings of diabetic retinopathy.
